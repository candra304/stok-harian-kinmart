Histori per Tanggal

Setiap tanggal tersimpan sendiri di HP ini dan tidak tertimpa tanggal lain. Buka tanggal lama untuk melihat atau mengubah lagi datanya — perubahan tersimpan otomatis di tanggal itu. Data hanya tersimpan selama kamu membuka aplikasi dari alamat / pintasan yang sama di HP ini.

Cadangan — Export & Import

Tab ini khusus cadangan data saja: Export untuk menyimpan backup dan Import untuk mengembalikan backup. Pengaturan tampilan, warna, dan font ada di menu Pengaturan (ikon gear).

Export ke Drive

Simpan backup data stok semua tanggal ke Google Drive. Menu bagikan HP terbuka — pilih Drive → Simpan ke Drive. Kalau menu bagikan tidak muncul di HP kamu, file backup otomatis terunduh ke HP dan bisa di-upload lewat aplikasi Drive.

Import dari Drive

Kembalikan data stok dari file backup, misalnya setelah ganti HP. Pilih file backup-nya dari Google Drive atau penyimpanan HP — data yang tersimpan sekarang akan diganti dengan isi file itu.
